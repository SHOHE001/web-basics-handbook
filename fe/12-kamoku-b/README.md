### 2. 擬似言語の書き方

IPA は試験の資料として「擬似言語の記述形式」を公開しており、問題はその決まりに従って書かれます。ここでは要点をわかりやすく整理し、Python との対応を添えて紹介します。正式な定義については IPA の資料で確認してください。

#### 宣言と代入

| 擬似言語 | 意味 | Python |
|---|---|---|
| `○整数型: sum(整数型の配列: a)` | 関数の宣言。整数を返す `sum` という関数で、整数の配列 `a` を受け取る | `def sum(a):` |
| `○show(文字列型: s)` | 手続（値を返さない関数）の宣言 | `def show(s):` |
| `整数型: i, total` | 変数の宣言 | （宣言は不要） |
| `total ← 0` | 代入（右辺の値を左辺の変数に入れる） | `total = 0` |
| `/* 注釈 */` または `// 注釈` | 注釈（コメント） | `# 注釈` |
| `return total` | 値を返して関数を終える | `return total` |

型には、整数型・実数型・文字型・文字列型・論理型（`true` / `false`）などがあります。配列は `{1, 2, 3}` のように書き、`a[i]` で各要素を指します。値がまだ入っていない状態は `未定義` と表します。

#### 選択と繰返し

```
if (条件式1)
  処理1
elseif (条件式2)
  処理2
else
  処理3
endif
```

```
while (条件式)          // 条件が真の間くり返す（前判定）
  処理
endwhile

do                      // 処理を 1 回やってから条件を調べる（後判定）
  処理
while (条件式)

for (i を 1 から n まで 1 ずつ増やす)
  処理
endfor
```

| 擬似言語 | Python |
|---|---|
| `if (x > 0)` … `elseif (x = 0)` … `else` … `endif` | `if x > 0:` … `elif x == 0:` … `else:` |
| `while (i ≦ n)` … `endwhile` | `while i <= n:` |
| `do` … `while (条件)` | （Python にはない。`while True:` の最後で `if not 条件: break`） |
| `for (i を 1 から n まで 1 ずつ増やす)` | `for i in range(1, n + 1):` |
| `for (i を n から 1 まで 1 ずつ減らす)` | `for i in range(n, 0, -1):` |

#### 演算子と優先順位

優先順位の高い順に並べると、次のとおりです。

| 優先順位 | 演算子 | 意味 | Python |
|---|---|---|---|
| 高 | `( )` | 括弧の中を先に計算 | `( )` |
| ↑ | `not` `+` `−`（単項） | 否定、符号 | `not` `+` `-` |
| | `×` `÷` `mod` | 掛け算、割り算、割り算の余り | `*` `/`（`//`）`%` |
| | `+` `−` | 足し算、引き算 | `+` `-` |
| | `=` `≠` `<` `≦` `>` `≧` | 比較 | `==` `!=` `<` `<=` `>` `>=` |
| ↓ | `and` | 論理積 | `and` |
| 低 | `or` | 論理和 | `or` |

> [!CAUTION]
> 擬似言語では、<mark>**`=` は「等しいか」を表す比較であり、代入は `←`**</mark> を使う。Python の `=`（代入）と `==`（比較）の感覚で読むと、`if (x = 0)` を代入と読み違えてしまう。また、整数どうしの `÷` の結果の扱いや、配列の要素番号が 1 から始まるかどうかは、**問題文と記述形式の注記で必ず確認** する。

### 3. トレース表の作り方

**トレース** とは、プログラムを人間が 1 行ずつ実行して、変数の値の変化を追うことです。紙（CBT では配布されるメモ用紙）に表を作って進めます。

例として、2 つの整数の最大公約数を求めるプログラム（ユークリッドの互除法）の動きを追ってみます。

```
○整数型: gcd(整数型: a, 整数型: b)
  整数型: r
  while (b ≠ 0)
    r ← a mod b
    a ← b
    b ← r
  endwhile
  return a
```

`gcd(48, 18)` のトレース表:

| 回 | `b ≠ 0` ? | r ← a mod b | a ← b | b ← r |
|---|---|---|---|---|
| 開始 | ― | ― | 48 | 18 |
| 1 | 真 | 48 mod 18 ＝ 12 | 18 | 12 |
| 2 | 真 | 18 mod 12 ＝ 6 | 12 | 6 |
| 3 | 真 | 12 mod 6 ＝ 0 | 6 | 0 |
| 4 | **偽** → ループを抜ける | | | |

戻り値は `a` ＝ **6** です。48 と 18 の最大公約数は 6 なので、正しく動いていることがわかります。

トレースのコツ:

1. **変数ごとに列を作る**: 頭の中だけで覚えようとしない
2. **条件の判定も列にする**: 「何回目でループを抜けたか」が答えに直結する問題が多い
3. **代入の順番を守る**: `a ← b` の後の `b ← r` では、**更新後** の `a` ではなく `r` を使うため、1 行ずつ値を確定させる
4. **小さい入力で試す**: 問題文の例が大きければ、要素数 2〜3 個の小さな例で動きをつかむ

### 4. 空欄補充問題の解き方

科目 B でよく出題されるのは、プログラムの一部が空欄になっており、そこに入る正しい式や文を選択肢から選ぶ形式です。次のような自作の例題で解き方の手順を確かめてみましょう。

**例題**: 次の関数 `countAbove` は、整数の配列 `data` の要素のうち、`border` より大きい要素の個数を返す。空欄 `[ア]` に入る式はどれか。配列の要素番号は 1 から始まる。

```
○整数型: countAbove(整数型の配列: data, 整数型: border)
  整数型: count, i
  count ← 0
  for (i を 1 から dataの要素数 まで 1 ずつ増やす)
    if ( [ア] )
      count ← count + 1
    endif
  endfor
  return count
```

- ア: `data[i] ≧ border`
- イ: `data[i] > border`
- ウ: `data[count] > border`
- エ: `i > border`

**解き方の手順**:

1. **関数が何をするかを日本語で確かめる**: 「border より **大きい** 要素を数える」
2. **選択肢の違いに注目する**: アとイは `≧` か `>` かの違い、ウは添字が `count` になっている点、エは要素ではなく番号 `i` を比べている点が異なる
3. **小さな例で試す**: `data ＝ {3, 8, 5, 10}`、`border ＝ 5` の場合、5 より大きいのは 8 と 10 の **2 個** が正解になる
   - アだと 5 も含めて数えるため 3 個 → 誤り
   - ウは `count` が 0 のときに `data[0]` を参照してしまう → 誤り
   - エは番号 1〜4 と 5 を比べるため 0 個 → 誤り
4. 答えは **イ**

「境目の値（ここでは border と同じ 5）を例に含める」と、`>` と `≧` の違いがはっきりと表れます。これは FE Chapter 9 で扱った境界値分析と同じ考え方です。

## つまずきポイント

> [!CAUTION]
> 科目 B で **Python 経験者ほど陥りやすい** 読み違いのリストである。擬似言語の決まりは Python とは異なる。

- <mark>**`=` は比較、`←` が代入**</mark>: Python とは使う記号が違う
- <mark>**要素番号の始まり**</mark>: 問題文の「配列の要素番号は 1 から始まる」という記述を確認する
- <mark>**`for` の「n まで」は n を含む**</mark>: Python の `range(1, n + 1)` に相当する
- **後判定の `do` … `while`**: 条件が最初から偽であっても、中の処理は 1 回実行される
- **代入の順番**: 同じ行で同時に値が入れ替わるのではなく、1 行ずつ順番に確定する

## 本文

### 1. 企業と組織

- **経営理念**: 企業が何のために存在するかという根本の考え
- **CSR（企業の社会的責任）**: 利益だけでなく、環境・人権・地域社会などへの責任を果たすこと
- **SDGs**: 2030 年までに達成を目指す、国連の 17 の持続可能な開発目標
- **コーポレートガバナンス**: 経営者が株主などのために適切に経営しているかを監視する仕組み

#### 組織の形

| 形 | 特徴 |
|---|---|
| **職能別組織** | 営業・製造・経理など、仕事の種類で分ける |
| **事業部制組織** | 製品や地域ごとに事業部を作り、事業部が利益に責任を持つ |
| **マトリックス組織** | 職能と事業（プロジェクト）の 2 つの軸を組み合わせる。上司が 2 人になる |
| **プロジェクト組織** | 目的のために各部門から人を集め、終われば解散する |

役職の略語として、**CEO**（最高経営責任者）、**CIO**（最高情報責任者。IT 戦略の責任者）、**CISO**（最高情報セキュリティ責任者）などがあります。

### 2. 会計と財務

#### 財務諸表

| 書類 | 表すもの |
|---|---|
| **貸借対照表（B/S）** | ある時点での **財産の状態**（資産 ＝ 負債 ＋ 純資産） |
| **損益計算書（P/L）** | ある期間の **もうけの流れ**（収益 − 費用 ＝ 利益） |
| **キャッシュフロー計算書** | ある期間の **お金の出入り** |

#### 損益計算書の利益の段階

```
売上高
 − 売上原価                     → 売上総利益（粗利）
 − 販売費及び一般管理費          → 営業利益（本業のもうけ）
 ＋ 営業外収益 − 営業外費用      → 経常利益（ふだんの活動全体のもうけ）
 ＋ 特別利益 − 特別損失          → 税引前当期純利益
 − 法人税など                   → 当期純利益
```

#### 損益分岐点

費用は、売上に関係なくかかる **固定費**（家賃、正社員の給料）と、売上に比例して増える **変動費**（材料費）に分けられます。売上と費用がちょうど等しくなる売上高が **損益分岐点売上高** です。

> [!CAUTION]
> <mark>**損益分岐点売上高 ＝ 固定費 ÷ (1 − 変動費率)**</mark>。変動費率 ＝ 変動費 ÷ 売上高。ここで「1 − 変動費率」を忘れて固定費 ÷ 変動費率と計算するミスが定番。式を丸暗記するより、「売上 1 円あたり、固定費の回収に使える分は (1 − 変動費率) 円」と理解しておくと崩れない。

**例題**: 固定費 300 万円、変動費率 0.4（売上の 40% が変動費）なら

300 ÷ (1 − 0.4) ＝ 300 ÷ 0.6 ＝ **500 万円**

**実例**: 学園祭の模擬店で、テント代や機材のレンタル代（固定費）が 3 万円、1 杯 300 円のジュースの材料費（変動費）が 1 杯 120 円なら、変動費率は 0.4。損益分岐点は 3 万 ÷ 0.6 ＝ 5 万円、つまり約 167 杯売ってやっと赤字を抜けます。

#### そのほかの会計の用語

- **減価償却**: パソコンなど長く使う設備の購入費を、使う年数に分けて少しずつ費用にすること
- **在庫の評価**: 仕入れ値が変わるとき、払い出した在庫の値段を、先に仕入れた順とみなす **先入先出法** や、平均でみなす **総平均法・移動平均法** などで決める
- **ROE**（自己資本利益率）: 株主が出したお金でどれだけ利益を上げたか

### 3. 経営戦略

| 手法 | 中身 |
|---|---|
| **SWOT 分析** | 自社の **強み・弱み**（内部）と、外部の **機会・脅威** の 4 つで整理する |
| **3C 分析** | 顧客（Customer）・競合（Competitor）・自社（Company）の 3 つの視点で分析する |
| **PPM** | 市場の成長率と自社の占有率の 2 軸で、事業を 4 つに分類する（下表） |
| **ファイブフォース分析** | 業界の競争の強さを、5 つの力（新規参入・代替品・買い手・売り手・既存の競合）で分析する |
| **コアコンピタンス** | 他社がまねできない、自社の中核となる強み |
| **ベンチマーキング** | 優れた他社のやり方と比べて、自社を改善する |

#### PPM の 4 分類

| | 占有率が高い | 占有率が低い |
|---|---|---|
| **成長率が高い** | 花形（さらに投資して育てる） | 問題児（投資して花形にするか、撤退するか） |
| **成長率が低い** | 金のなる木（投資が少なく、稼げる） | 負け犬（撤退を検討） |

#### 企業の協力のしかた

**アライアンス**（提携）、**M&A**（合併・買収）、**アウトソーシング**（業務の外部委託）、**OEM**（他社のブランドで製品を作る）などがあります。

### 4. マーケティング

- **STP**: 市場を細かく分け（**S**egmentation）、狙う層を決め（**T**argeting）、競合との違いをはっきりさせる（**P**ositioning）
- **4P**: 売り手から見た 4 つの要素。製品（Product）・価格（Price）・流通（Place）・販売促進（Promotion）
- **4C**: 4P を買い手から見直したもの。顧客価値・顧客の負担・入手の容易さ・コミュニケーション
- **プロダクトライフサイクル**: 製品は導入期 → 成長期 → 成熟期 → 衰退期をたどる
- **ロングテール**: ネット販売では、1 つ 1 つは少ししか売れない商品も、種類が膨大なので合計すると大きな売上になる

**実例**: 動画配信サービスが「学生プラン」を用意するのは、学生という層を切り出して（セグメンテーション）狙い（ターゲティング）、価格（Price）を調整した例です。

### 5. ビジネスでの IT 活用

| 用語 | 中身 |
|---|---|
| **BSC**（バランススコアカード） | 財務・顧客・業務プロセス・学習と成長の 4 つの視点で、戦略と目標を管理する |
| **KGI / KPI** | 最終的な目標の指標 / そこへ向かう途中経過の指標 |
| **CRM** | 顧客の情報を一元管理して、長く良い関係を築く |
| **SCM** | 調達・生産・物流・販売のつながり（供給連鎖）全体を最適化する |
| **ERP** | 会計・人事・生産・販売など、企業全体の基幹業務を統合して管理する |
| **BPR** | 業務のやり方を根本から作り直す |
| **RPA** | パソコンの定型作業（転記・集計など）をソフトウェアのロボットに自動で行わせる |
| **DX**（デジタルトランスフォーメーション） | デジタル技術を使って、製品・サービスやビジネスのやり方そのものを変える |

#### e-ビジネス

- **EC**（電子商取引）: 企業間の **BtoB**、企業と消費者の **BtoC**、消費者どうしの **CtoC**（フリマアプリなど）
- **O2O**: ネット（Online）から実店舗（Offline）へお客さんを誘導する（アプリのクーポンでお店に来てもらう）
- **フィンテック**: 金融とITを組み合わせたサービス（スマホ決済、家計簿アプリ）
- **シェアリングエコノミー**: 個人の持つモノや場所、スキルを貸し借りする

### 6. システム戦略と調達

- **エンタープライズアーキテクチャ（EA）**: 組織全体の業務とシステムの全体像を整理し、最適化する手法
- **情報システム戦略**: 経営戦略に沿って、どんなシステムに投資するかを決めたもの

システムを外部に発注するときの流れ:

1. **RFI**（情報提供依頼）: 候補の企業に、技術や製品の情報を出してもらう
2. **RFP**（提案依頼書）: 作ってほしいシステムの要件を示して、提案を依頼する
3. **提案書・見積書** を受け取り、評価して発注先を選ぶ

### 7. 法務

#### 知的財産権

| 権利 | 守るもの | 手続き |
|---|---|---|
| **著作権** | 思想や感情を創作的に表現したもの（文章、音楽、絵、**プログラム**） | 創作した時点で自動的に発生（登録不要） |
| **特許権** | 高度な発明 | 出願して登録が必要 |
| **実用新案権** | 物の形や構造の考案 | 出願・登録 |
| **意匠権** | 製品のデザイン | 出願・登録 |
| **商標権** | 商品やサービスのマーク・名前 | 出願・登録 |

> [!CAUTION]
> プログラムは著作権で守られるが、<mark>**アルゴリズム（解き方そのもの）、プログラム言語、規約（インタフェースの取り決めなど）は著作権の保護対象外**</mark>。また会社の業務として社員が作ったプログラムは、契約などで別に定めない限り **会社が著作者** になる（職務著作）。この 2 点は選択肢でよく入れ替えられる。

**実例**: このハンドブックが「書籍の本文は写さず、章の分け方だけを参考にして中身は自分の言葉で書く」という方針をとっているのも、著作権を意識したものです。

#### 営業秘密と不正競争防止法

顧客名簿や製造ノウハウが **営業秘密** として守られるには、①秘密として管理されている、②事業に役立つ、③世間に知られていない、の 3 つの条件が必要です。

#### セキュリティ関連の法律

| 法律 | 中身 |
|---|---|
| **不正アクセス禁止法** | 他人の ID・パスワードを無断で使ったり、セキュリティの穴を突いたりしてシステムに入ることを禁じる。他人の ID・パスワードを本人に無断で第三者に教えることも禁止 |
| **個人情報保護法** | 個人情報を扱う事業者の義務を定める。病歴・犯罪歴など特に配慮が必要な情報は **要配慮個人情報** として、取得に原則本人の同意が必要 |
| **刑法（ウイルス作成罪など）** | 正当な理由なくコンピュータウイルスを作ったり、配ったりすることを罰する |
| **プロバイダ責任制限法（情報流通プラットフォーム対処法）** | ネット上の権利侵害への対応や、発信者情報の開示を定める |

Web 編 Ch6 の冒頭で「他人のサービスに試すと法律違反」と書いたのは、主に不正アクセス禁止法のことです。

#### 労働と取引の法律

- **労働者派遣**: 派遣元と雇用契約を結んだ人が、**派遣先の指揮命令** を受けて働く
- **請負**: 仕事の完成を約束する契約。働く人への指揮命令は **請負事業者自身** が行う。発注者が請負の作業者に直接指示を出すと、実態が派遣になってしまう（**偽装請負**）
- **準委任**: 仕事の完成ではなく、作業をきちんと行うこと自体を約束する契約
- **下請法**: 発注元の大きな会社が、下請けの会社に代金の支払いを遅らせたり、不当に値引きさせたりすることを禁じる
- **PL 法**（製造物責任法）: 製品の欠陥で被害が出たとき、製造者の過失を証明しなくても損害賠償を求められる

### 8. 標準化

| 規格 | 中身 |
|---|---|
| **ISO** | 国際標準化機構の規格。ISO 9001（品質）、ISO 14001（環境）、ISO/IEC 27001（情報セキュリティ） |
| **JIS** | 日本産業規格 |
| **IEEE** | 電気・電子分野の規格。無線 LAN の IEEE 802.11 など |
| **JAN コード / QR コード** | 商品のバーコード / 2 次元コード |

### 9. データ分析と意思決定

#### QC 七つ道具

| 道具 | 使い道 |
|---|---|
| **パレート図** | 項目を多い順に並べた棒グラフと累積比率の折れ線。「どの問題から手をつけるか」を決める |
| **特性要因図** | 結果（特性）と原因の関係を魚の骨の形で整理する |
| **管理図** | 品質のばらつきが、管理の上限・下限の中に収まっているかを見る |
| **散布図** | 2 つの量の関係（相関）を点で見る |
| **ヒストグラム** | データの分布を棒グラフで見る |
| **チェックシート** | データを漏れなく記録・集計するための表 |
| **層別** | データを属性ごとに分けて比べる |

**実例**: アプリへの問合せを種類別に数えて多い順に並べると、上位 2〜3 種類で全体の大半を占めていることが多い。パレート図で見つけた上位から対策するのが効率的です。

#### 待ち行列

レジや窓口に人が並ぶ様子を数式で扱う理論です。FE では次の式がよく使われます（客の来方と処理時間がランダムな、もっとも基本的なモデル）。

```
利用率 ρ ＝ 平均到着率 ÷ 平均サービス率（＝ 平均サービス時間 ÷ 平均到着間隔）
平均待ち時間 ＝ ρ ÷ (1 − ρ) × 平均サービス時間
```

**例題**: 1 人の対応に平均 4 分かかる窓口に、平均 5 分おきに客が来るとき、ρ ＝ 4 ÷ 5 ＝ 0.8。平均待ち時間は 0.8 ÷ 0.2 × 4 ＝ **16 分**。利用率が 1 に近づくと、待ち時間は急激に長くなります。

#### そのほかの手法

- **線形計画法**: 限られた資源（材料・時間）の中で、利益が最大になる生産量の組合せを求める
- **デシジョンツリー**: 選択肢と起こりうる結果を木の形に書き、期待値を比べて決める
- **ABC 分析**: 商品を売上の大きい順に A・B・C に分けて、管理の重点を決める

## 手を動かすパート

損益分岐点と待ち行列は、式に数字を入れるだけで確かめられます。

```python
>>> fixed, variable_rate = 300, 0.4
>>> fixed / (1 - variable_rate)          # 損益分岐点売上高（万円）
500.0
>>> service, interval = 4, 5
>>> rho = service / interval
>>> rho / (1 - rho) * service            # 平均待ち時間（分）
16.000000000000004
```

最後の値が 16 ぴったりにならないのは、FE Chapter 3 で見た小数の誤差です。

## つまずきポイント

> [!CAUTION]
> ストラテジ系は **用語の主語（誰が・何を）** を入れ替えた選択肢が多い。とくに法務は主語を確認する。

- <mark>**損益分岐点の式**</mark>: 固定費 ÷ (1 − 変動費率)
- <mark>**営業利益と経常利益**</mark>: 本業だけか、営業外の収益・費用まで含むか
- <mark>**派遣と請負の指揮命令**</mark>: 派遣は派遣先が、請負は請負事業者が指示する
- **著作権は登録不要、特許権は登録が必要**: 権利の発生のしかたが違う
- **PPM の問題児と負け犬**: 成長率が高いのが問題児、低いのが負け犬（どちらも占有率は低い）

# 基本情報技術者試験 編

> Status: 完了（初版 2026-11-04）

Web 編（Chapter 1〜7）で「ブラウザの裏側」を一通り触ったあとに、同じ知識を **国家試験の言葉** で整理し直すためのパートです。Web 編と重なる分野（ネットワーク・セキュリティ・データベースなど）は、Web 編へのリンクで手を動かした体験とつなげます。

## この編で学ぶこと

- 基本情報技術者試験（FE）がどういう試験で、何を問われるのか
- 科目 A（知識）で出る 11 分野の要点を、身近な例で言える状態にする
- 科目 B（アルゴリズムと情報セキュリティ）の擬似言語を、Python に置き換えながら読めるようにする

## 試験の概要（2026 年 11 月 4 日時点）

| 項目 | 内容 |
|---|---|
| 主催 | IPA（情報処理推進機構）。国家試験「情報処理技術者試験」の 1 区分 |
| 位置づけ | IT パスポートの上、応用情報技術者の下。「IT エンジニアの入口」とされるレベル |
| 方式 | CBT（全国のテストセンターでパソコンを使って受ける） |
| 科目 A | 90 分・60 問・四肢択一。用語と計算の知識を幅広く問う |
| 科目 B | 100 分・20 問。アルゴリズムとプログラミング（擬似言語）16 問＋情報セキュリティ 4 問 |
| 合格基準 | 科目 A・科目 B とも 1000 点満点中 600 点以上（どちらか片方でも足りないと不合格） |
| 採点 | IRT（項目応答理論）。問題ごとの難易度を加味するので、単純な「正答数 ÷ 問題数」ではない |
| 受験手数料 | 7,500 円（税込） |

> [!CAUTION]
> <mark>**2026 年 12 月 28 日以降、FE の CBT 試験は休止が予定されています**</mark>（CBT システムの入れ替えのため。会場によってはそれより前に休止）。2027 年 1 月以降の実施方法は IPA が別途案内するとしています。さらに IPA は **2027 年度春ごろに新しい試験制度へ移行** する予定を公表しており、FE は継続、試験時間・問題数・科目 A 免除制度は変えない方針、科目 A の出題分野の分類体系は見直す、とされています。受験日を決める前に、必ず IPA の試験情報ページで最新の告知を確認してください。

### 科目 A 免除制度

IPA が認定した講座（専門学校・通信講座など）を受講し、その修了試験に合格すると、合格から 1 年間は科目 A が免除されて科目 B だけを受ければよくなります。独学の場合は関係ありません。

### 受験までの流れ

1. IPA のサイトから受験申込（CBT の会場と日時を選ぶ）
2. 当日、テストセンターで科目 A → 科目 B の順に受験（間に休憩を挟める）
3. 試験終了後すぐに画面でスコアが確認でき、後日 IPA から正式な合格発表

## この編の読み方

1. まず **3 章（基礎理論）と 4 章（アルゴリズム）** を先に読む。ここは他の章の計算問題の土台で、科目 B にも直結する
2. 次に 1・2・5〜9 章のテクノロジ系。Web 編を読んだ人は 7 章・8 章が楽に感じるはず
3. 10・11 章は暗記寄り。用語の意味を「身近な実例」と一緒に覚える
4. 最後に 12 章で擬似言語の問題を解く練習。IPA が公開しているサンプル問題・公開問題を併用する

各章のつくりは Web 編と同じです（この章で学ぶこと → 本文 → つまずきポイント → 重要な単語まとめ）。計算が絡む章には Python の確認用スクリプトを `code/` に置いてあります。
